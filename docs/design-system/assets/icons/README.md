# Icons

Собственные векторные иконки приложения из `ui/theme/AppIcons.kt`, переведённые в SVG путь в путь, сетка 24 × 24.

- Цветные значки разделов рисуются своими цветами и не перекрашиваются: `inbox.svg` (#23a9eb), `today.svg` (#fecb2f), `upcoming.svg` (#d30062), `anytime.svg` (#3ba39a), `someday.svg` (#cec493), `logbook.svg` (#51bd63), `evening.svg` (#91add9).
- Одноцветные иконки в коде нарисованы белым или чёрным и перекрашиваются при использовании. Здесь они сохранены в цвете, который получают чаще всего:
  - `area.svg` — `area-green` (#269c6e), значок области;
  - `tag.svg`, `tag-filled.svg` — `someday-grey` (#8f93a3), тег в списках и поиске; в поле тегов редактора — `anytime-teal`;
  - `bullet-list.svg`, `deadline.svg` — `checkbox-border` (#c7c7cc), неактивные иконки панели редактора; на фоне свайпа влево Bullet list белый.
- В колонке чекбокса иконки 20 dp, в панели редактора 24 dp, на фоне свайпа 22 dp.
- Служебные иконки (поиск, закрыть, стрелки, «•••», корзина) берутся из Material Icons и сюда не входят.
