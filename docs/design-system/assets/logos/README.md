# Logos

Иконка приложения — адаптивная иконка Android из `res/drawable/ic_launcher_*.xml`.

- `app-icon.svg` — целиком: фон #f4f5f6, синий круг #1070e0, белая галочка (штрих 4.5, скруглённые концы). Сетка 108 × 108.
- `app-icon-foreground.svg` — только знак: круг с галочкой, обрезанный по кругу. Монохромный вариант иконки в системе строится из него же.
- Отдельного логотипа-надписи у приложения нет: название «Things 2» набирается шрифтом `sans` (Roboto) Bold.
