# CalendarEvents

Блок событий календаря на «Сегодня» и в днях «Предстоящих»: плашка со строками событий и цветной полоской календаря у каждой.

## Размеры
- Плашка: фон `calendar-card` (`ThingsTheme.colors.calendarCard`), радиус `radius-chip` (10 dp), поля 10 dp, между строками 2 dp.
- Строка: полоска цвета календаря 3 × 11 dp с радиусом 1.5 dp, текст 15 sp; у событий со временем — колонка времени 72 dp.
- Цвет полоски берётся из календаря (пресеты `calendar-*`), иначе `calendar-default`; приглушённые элементы — `muted-grey`.
- До задач — 25 dp (`space-calendar-section`).
