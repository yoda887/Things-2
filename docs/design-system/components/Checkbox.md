# Checkbox

Квадратный чекбокс задачи со скруглением 23 % стороны; отметка заливает его `accent` от центра и прорисовывает галочку.

## Когда использовать
Слева в каждой строке задачи, в раскрытом редакторе и в пунктах чек-листа. У задач в «Когда-нибудь» и у проектов без даты — пунктирная рамка (`isDashed`), у отменённой задачи вместо галочки крестик.

## Что передаёт экран
- `checked`, `onCheckedChange` — состояние и обработчик (с вибрацией `CLOCK_TICK`).
- `size` — 16 dp в строке задачи (`size-checkbox`), 22 dp по умолчанию.
- `checkedColor` = `accent`, `uncheckedColor` = `checkbox-border`.
- `isDashed`, `isCancelled` — пунктирная рамка и крестик.

## Правила
- Толщина рамки — 7 % стороны, не меньше 1 dp; пунктир 3 dp / 2.5 dp.
- Без ripple: нажатие отзывается только вибрацией и анимацией заливки.
- Не перекрашивайте отмеченный чекбокс в цвет раздела — отметка всегда `accent`.
