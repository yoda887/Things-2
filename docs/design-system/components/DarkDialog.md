# DarkDialog

Тёмный модальный диалог в обеих темах: выбор проекта (Move), подтверждение удаления, меню.

## Когда использовать
Для решения, которое прерывает работу: куда перенести задачу, подтвердить удаление, удалить подзаголовок с задачами.

## Размеры
- Фон `dialog-bg`, радиус `radius-dialog` (32 dp), поля `space-dialog-inner`, ширина до 320 dp.
- Заголовок — `dialogTitle` (20 sp, Bold), строка выбора — `dialogRow` (19 sp), кнопки Cancel / Delete — `dialogButton` (18 sp, обычное начертание).
- Заголовок — белый, Bold; текст — белый с прозрачностью; основное действие — капсула `danger` (удаление) или строка со значком и галочкой `accent` (Move).

## Правила
- Отмена — текстовая кнопка слева, действие — справа.
- В Move текущий проект отмечен галочкой `accent` и подсвеченной строкой.
