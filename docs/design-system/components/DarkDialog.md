# DarkDialog

Тёмный модальный диалог в обеих темах: выбор проекта (Move), дата (When), теги, меню. Подтверждения удаления — светлые, см. «Диалог подтверждения» ниже.

## Когда использовать
Для выбора, который прерывает работу: куда перенести задачу, на когда её поставить, какие теги назначить.

## Размеры
- Фон `dialog-bg`, радиус `radius-dialog` (32 dp), поля `space-dialog-inner`, ширина до 320 dp.
- Заголовок — `dialogTitle` (20 sp, Bold), строка выбора — `dialogRow` (19 sp), кнопки Cancel / Delete — `dialogButton` (18 sp, обычное начертание).
- Заголовок — цветом `overlay-content`; пояснение — `meta-grey`; выбор — строка со значком и галочкой `accent` (Move).

## Правила
- Отмена — текстовая кнопка слева, действие — справа.
- В Move текущий проект отмечен галочкой `accent` и подсвеченной строкой.

## Поиск в Move — вытягивание тягой списка
Как в Things: поля поиска над списком в покое нет, его вытягивают тягой списка вниз.
- Тяга от верха списка идёт пружиной — вполовину хода пальца. Под заголовком раскрывается место под поле; само поле стоит на своём месте и проявляется со второй половины пути (капсула `radius-capsule`, фон `dialog-button`, лупа и «Пошук» по центру цветом `meta-grey`).
- Поле раскрыто целиком — оно останавливается, а список уходит ниже со всё большим сопротивлением, до 120 dp. Посередине открывшегося промежутка — своя стрелка вниз: широкая и пологая, 18 × 5 dp, линия 1.5 dp со скруглёнными концами, цветом `meta-grey`; проявляется вместе с промежутком.
- Список протянут на 24 dp ниже поля — можно отпускать: поле заливается `accent`, лупа и подпись становятся `on-accent`, стрелка синеет (`accent`), телефон щёлкает (CLOCK_TICK).
- Отпустили синее — список резко, без раскачки, возвращается под поле; поле серое с курсором слева, выезжает клавиатура, список приглушён до 40 %, стрелка уходит. Отпустили раньше — поле прячется.
- Толчок списка вверх прячет пустое поле без курсора; пока в поле курсор или текст, оно видно целиком.
- Сплошная подсветка выбранного результата (`accent`, текст `on-accent`) остаётся фоном — поверх она закрыла бы текст.

## Диалог подтверждения
Подтверждение удаления задачи, задач, проекта, области, подзаголовка с задачами, группы тегов — только общий компонент `ThingsConfirmDialog` (`ui/components/ThingsConfirmDialog.kt`).
- Светлый, по теме приложения: фон `bg` (в тёмной теме — тёмный), радиус `radius-dialog` (32 dp), ширина 300 dp.
- Заголовок — `dialogTitle` цветом `text-primary`; пояснение — `dialogBody` цветом `text-secondary`.
- Слева текстовая кнопка отмены (`dialogButton`, `text-primary`), справа капсула действия: `danger` для удаления, иначе `accent`; текст на ней `on-accent`.
- Тексты — из `strings.xml` с переводами, количество задач — через plurals.
- Стандартный Material `AlertDialog` запрещён — его ловит `DesignSystemEnforcementTest`.
