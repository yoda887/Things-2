# DropPlaceholder

Серая плашка, которая показывает, куда встанет перетаскиваемая задача, подзаголовок или новая задача из «+».

## Когда использовать
Всё время, пока что-то тянут по списку: на месте поднятой задачи, под кнопкой «+», под поднятым подзаголовком. Не исчезает, когда «+» стоит над «отменой».

## Размеры
- Цвет `drop-placeholder` с прозрачностью 50 %, радиус `radius-task`.
- Для «+» — 44 dp высотой (`size-drop-gap`); после отпускания тает по мере того, как соседи раздвигаются под новую задачу.
- На главном экране (проекты) — 46 dp, фон `home-drop-placeholder` без прозрачности, радиус 10 dp, поля 4 dp сверху и снизу.

## Правила
- Смена места плашки сопровождается вибрацией `CLOCK_TICK`, первое появление — без неё.
