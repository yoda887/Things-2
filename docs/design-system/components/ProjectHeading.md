# ProjectHeading

Подзаголовок внутри проекта: название цветом `deep-blue`, кнопка «•••» с меню и тонкая линия под ним.

## Когда использовать
Чтобы разделить большой проект на группы задач. Создаётся из меню проекта или перетаскиванием «+» к левому краю списка.

## Что передаёт экран
- Подзаголовок (название), режим правки, обработчики Rename / Archive / Delete.
- Удаление спрашивает подтверждение, если под подзаголовком есть задачи; архивирование отмечает их выполненными.

## Размеры
- Строка 40 dp, текст `project-heading` (19 sp, SemiBold, `deep-blue`), «•••» 26 dp того же цвета; поля строки 8 dp.
- Над подзаголовком 22 dp, под ним 4 dp; линия `divider` 0.6 dp.
- Меню — фон `dialog-bg`, пункты 17 sp белым, Delete — `upcoming-red`.

## Перетаскивание
Подзаголовок едет вместе со своими задачами: поднимается (масштаб 1.03, тень 8 dp, фон `bg`, `radius-heading`), под ним стопка из одного-двух слоёв по числу задач (обводка `hairline`), на месте вставки — плашка `drop-placeholder`.
