# Settings

Строка «Налаштування» внизу главного экрана и экран настроек, который она открывает. На экране настроек — синхронизация с Google Tasks и [DriveBackupCard](DriveBackupCard.md).

## Строка на главном экране
- Без фона: значок шестерёнки (Outlined Settings) 16 dp и подпись «Налаштування» — `bodyLarge` (16 sp, обычный), оба цветом `text-secondary`; между ними 6 dp.
- По центру экрана по горизонтали; область нажатия — высота 46 dp (высота строки главного экрана), поля 12 dp, при нажатии — волна со скруглением `radius-chip`.
- Последняя в списке, на одной высоте с кнопкой «+»: снизу 16 dp + половина разницы высот кнопки (56 dp) и строки, сверху 16 dp.
- Где стоит:
  - список проектов и областей короче экрана — строка прижата к нижнему краю, промежуток над ней растягивается;
  - список длиннее экрана — строка идёт сразу под последней областью, видна, когда список прокручен до конца.

## Экран настроек
- Открывается обычным переходом между экранами (рост из центра); «Назад» — стрелка вверху слева или системный жест.
- Верхняя строка: только стрелка «Назад» 24 dp цветом `text-primary`, фон прозрачный.
- Заголовок «Налаштування» — `largeTitle` цветом `text-primary`.
- Под ним карточки с промежутком 16 dp, поля списка 14 dp от краёв экрана:
  - «Синхронізація з Google Tasks» — раскрывается нажатием на заголовок: поле токена и кнопка «Синхронізувати завдання зараз»;
  - «Резервна копія в Google Drive» ([DriveBackupCard](DriveBackupCard.md)).
- Кнопки «+» на экране настроек нет.

## Правила
- Все надписи — из `strings.xml` (en/uk/ru): `settings_title`.
- Новые настройки — отдельными карточками на этом экране, не на главном.
