# Switch

Переключатель настроек `ThingsSwitch` — один вид на всех экранах: стандартный переключатель Material 3.

## Когда использовать
Для включения и выключения настройки на экране настроек: «Місяць словом у датах», «Сьогодні» по проєктах, автоматическая резервная копия, синхронизация между устройствами ([DriveBackupCard](DriveBackupCard.md)). Не используйте `Switch` из Material напрямую — только `ThingsSwitch`.

## Что передаёт экран
- `checked`, `onCheckedChange` — состояние и обработчик.

## Вид
- Стандартный Material 3: размер, бегунок, анимация и вид выключенного — по умолчанию.
- Включённый — дорожка `accent`.

## Правила
- Переключатель стоит справа в строке настройки, подпись — слева; нажатие на всю строку переключает его, где строка — отдельная карточка.
- Цвета не переопределяйте на месте: новый вид — только правкой `ThingsSwitch` и этой спецификации.
