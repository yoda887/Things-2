# TagChip

Капсула тега в раскрытом редакторе и в окне быстрого добавления.

## Размеры
- Фон `tag-chip-bg`, текст `tag-chip-text` 16 sp обычного начертания (`tagChip`), радиус `radius-chip` (10 dp), поля 10 dp по бокам и 4 dp сверху и снизу.
- Название тега — всегда в одну строку: без переноса; если тег шире всей строки — обрезается многоточием.
- Чипы идут в строку с переносом: 8 dp между ними, 6 dp между строками; строка чипов начинается с 24 dp (`space-editor-indicators-start`).

## Правила
- В списках тег показывается только иконкой Tag цветом `someday` справа от названия; чипы — только в редакторе.
- Контраст текста на фоне 3.9:1 — ниже 4.5:1, как в источнике.
