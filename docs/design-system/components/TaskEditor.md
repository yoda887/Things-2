# TaskEditor

Раскрытый на месте редактор задачи: карточка цвета фона поверх затемнённого списка с названием, заметками и панелью свойств.

## Когда использовать
По тапу на строку задачи и при создании задачи кнопкой «+». Другой задачи в это время раскрыто быть не может.

## Что передаёт экран
- Задачу и обработчики сохранения, удаления, переноса.
- `autoFocusTitle` — для новой задачи из «+»: курсор в названии, клавиатура выезжает вместе с карточкой, на клавиатуре кнопка «Done», которая сворачивает задачу.

## Размеры
- Отступы: сверху 20 dp, снизу 16 dp, слева 12 dp, справа 18 dp; соседи отходят на 42 dp (`space-editor-gap`).
- Название — `taskTitle` цветом `editor-text`, заметки — `editorNotes` цветом `text-notes`, плейсхолдеры «New To-Do» и «Notes» — `meta-grey`.
- Внизу: строка «Сегодня» / даты (`editorDate`), чипы тегов (`tag-chip-bg`), справа иконки Tag, Bullet list, Deadline цветом `checkbox-border`; между иконками 16 dp.
- Карточка — `radius-task`, тень `elevation-card`. Под ней — ссылка на проект («Things 2 ›»), внизу экрана — панель действий.

## Правила
- Карточка цвета фона (`bg`) с тенью `elevation-card`; в тёмной теме текст редактора светлый.
- Пока задача раскрыта, фон списка плавно меняется на `list-dim`, остальные строки затемняются до 30 %.
- Сворачивается по тапу вне неё, по «Done» у новой задачи и по кнопке «назад»; изменения сохраняются при сворачивании.
