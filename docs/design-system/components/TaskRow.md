# TaskRow

Строка задачи в списке: чекбокс, название и, при необходимости, подпись с проектом, маркеры заметок и тегов справа.

## Когда использовать
Во всех списках задач: Входящие, Сегодня, Предстоящие, В любое время, Когда-нибудь, проект, область, поиск.

## Что передаёт экран
- Задачу: название, проект или область (подпись), дату (маркер «Сегодня» — звезда `today`, вечер — значок Evening, дедлайн — флаг с «через N дн.»), наличие заметок, чек-листа и тегов (иконки справа).
- Состояния: выбрана (`accent-selection`), перетаскивается, затемнена при раскрытой соседней задаче (30 %).

## Размеры
- Высота 46 dp без подписи; отступы `space-row-start` 10 dp и `space-row-end` 8 dp; чекбокс 16 dp, до текста 8 dp.
- Название — `taskTitle`, в одну строку с многоточием; подпись — `taskSubtitle` цветом `text-secondary`.

## Правила
- В покое у строки нет фона, рамки и тени.
- Свайп влево открывает выбор (фон `accent`, иконка Bullet list), вправо — «Когда» (фон `swipe-when`); фон за строкой — `radius-task`.
