# UpcomingHeaders

Заголовки «Предстоящих»: день (крупное число, линия и название дня) и месяц (линия и название месяца).

## Размеры
- День: число `upcoming-day-number` (32 sp Bold, `text-primary`), справа через 8 dp — линия `divider` 0.6 dp и под ней название дня 16 sp цветом `text-secondary` с прозрачностью 50 %; отступы 36 dp сверху и 10 dp снизу.
- Месяц: линия `divider` 0.6 dp, через 6 dp название месяца 16 sp Bold; отступы 40 dp сверху и 8 dp снизу.

## Правила
- Это границы секций: задача, брошенная над заголовком, встаёт последней в предыдущем дне; перенос через заголовок меняет дату задачи на дату его раздела.
