# WhenDialog

Тёмный диалог выбора даты: «Сегодня», «Сегодня вечером», календарь на месяц, «Когда-нибудь» и «Clear».

## Когда использовать
По иконке календаря в редакторе, по свайпу строки вправо и по кнопке даты в панели выбранных. Диалог вырастает из точки вызова.

## Размеры
- Карточка 336 dp шириной, радиус 32 dp, фон `dialog-bg`, поля 16 dp по бокам и 18 dp сверху и снизу; кнопка закрытия — `dialog-close`.
- Заголовок 20 sp, белый. Строки «Сегодня», «Сегодня вечером», «Когда-нибудь» — 46 dp, радиус 8 dp, текст 19 sp белый, иконка 18 dp в колонке 35 dp; активная строка отмечена галочкой `accent`.
- Календарь: ячейка 45 dp высотой, число 19 sp, подпись месяца 13 sp; сегодняшний день обведён `accent` 1.5 dp с радиусом 6 dp; дни недели — `when-secondary`, 15 sp.
- «Clear» — кнопка 40 dp высотой, фон `when-clear`, белый текст; над ней 37 dp.

## Движение
- Появление: рост с масштаба 0.45 за 180 мс, проявление за 60 мс; закрытие — 130 мс; фон за диалогом затемняется на 20 %.
