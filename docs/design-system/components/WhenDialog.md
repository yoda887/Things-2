# WhenDialog

Тёмный диалог выбора даты: «Сегодня», «Сегодня вечером», календарь на месяц, «Когда-нибудь» и «Clear».

## Когда использовать
По иконке календаря в редакторе, по свайпу строки вправо и по кнопке даты в панели выбранных. Диалог вырастает из точки вызова.

## Размеры
- Карточка 336 dp шириной, радиус `radius-dialog` (32 dp), фон `dialog-bg`, поля 16 dp по бокам и 18 dp сверху и снизу; кнопка закрытия — `dialog-button`.
- Заголовок «When?» — `dialogTitle` (20 sp, Bold); строки «Сегодня», «Сегодня вечером», «Когда-нибудь» — `dialogRow` (19 sp) цветом `overlay-content`.
- Строки — 46 dp, радиус `radius-task` (8 dp), иконка 18 dp в колонке 35 dp; активная строка отмечена галочкой `accent`.
- Календарь: ячейка 45 dp высотой, число — `dialogRow` (19 sp), подпись месяца — `bodySmall` (13 sp); сегодняшний день обведён `accent` 1.5 dp с радиусом `radius-small` (6 dp); дни недели — `subhead` (15 sp) цветом `meta-grey`.
- «Clear» — кнопка-капсула 40 dp высотой, фон `clear-action`, текст `dialogButton` (18 sp, обычное начертание) цветом `overlay-content`; над ней 37 dp.

## Движение
- Появление: рост с масштаба 0.45 за 180 мс, проявление за 60 мс; закрытие — 130 мс; фон за диалогом затемняется на 20 %.
